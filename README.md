# POWER : Prévision de la consommation électrique en France

Projet académique réalisé dans le cadre du S9 à l'ENSEIRB-MATMECA.

L'objectif du projet est de développer une approche de prévision de la consommation électrique en France à partir de données de consommation, de production, de météo et de calendrier.

Projet en cours.
